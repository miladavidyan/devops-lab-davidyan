# CONTRIBUTING

## Правила участия в проекте

- Все изменения необходимо выполнять в отдельных ветках.
- Перед отправкой изменений необходимо проверить работоспособность проекта.
- Сообщения коммитов должны быть понятными и краткими.
- Изменения в основную ветку `main` вносятся через Pull Request.
- Перед слиянием Pull Request необходимо проверить внесенные изменения.
