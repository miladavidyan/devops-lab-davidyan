# CONTRIBUTING

## Правила участия в проекте

- Все изменения выполняются в отдельных ветках.
- Сообщения коммитов должны быть краткими и понятными.
- Перед отправкой изменений необходимо проверить файлы проекта.
- Изменения в ветку `main` вносятся через Pull Request.
- Перед слиянием Pull Request необходимо проверить внесенные изменения.
