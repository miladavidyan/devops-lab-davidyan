# Создание страниц сайта

В каталоге docs были созданы четыре основные страницы:

index.md — главная страница;
about.md — информация обо мне;
projects.md — профессиональные проекты;
contacts.md — контактная информация.

Навигация между страницами была настроена в файле mkdocs.yml.

Пример настройки:

nav:
  - Главная: index.md
  - О себе: about.md
  - Проекты: projects.md
  - Контакты: contacts.md

Таким образом, пользователь может переходить между всеми основными разделами сайта через верхнее меню.

# 3. Настройка темы Material for MkDocs

Для оформления сайта была использована тема Material for MkDocs.

В конфигурационном файле mkdocs.yml была указана тема:

theme:
  name: material
  language: ru

Также были подключены функции навигации и поиска.

Для обработки Markdown внутри HTML-блоков были подключены расширения:

markdown_extensions:
  - attr_list
  - md_in_html

Это позволило использовать собственные HTML-контейнеры совместно с обычной Markdown-разметкой.

# 8. Пользовательское оформление сайта

Для изменения стандартного оформления Material for MkDocs был создан файл:

docs/stylesheets/extra.css

Он был подключён в mkdocs.yml:

extra_css:
  - stylesheets/extra.css

Для сайта была выбрана следующая цветовая палитра:

Фон:          #F5F6F3
Хедер:        #CAD2C5
Акцент:       #84A98C
Основной текст: #354F52

В качестве основного шрифта использовался Inter.

Для заголовков первого уровня использовался шрифт Playfair Display Italic.

Пример:

.md-typeset h1 {
    font-family: "Playfair Display", serif;
    font-style: italic;
    font-weight: 600;
}

Для проектов и информационных блоков были созданы карточки:

.project-card {
    background: #FFFFFF;
    border: 1px solid #DDE4DA;
    border-radius: 18px;
    padding: 24px;
    margin: 20px 0;
    box-shadow: 0 8px 24px rgba(47, 62, 70, 0.06);
}

Это позволило адаптировать стандартную тему MkDocs под стиль персонального портфолио.

# 12. Публикация проекта на GitHub

На GitHub был создан публичный репозиторий:

Основная ветка была переименована в main:

git branch -M main

После этого проект был отправлен на GitHub:

git push -u origin main

Команда выполнилась успешно, после чего все исходные файлы проекта появились в удалённом репозитории.
